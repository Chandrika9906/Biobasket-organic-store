# BioBasket - Organic Store 🌿

A web-based organic products e-commerce store offering a range of natural and organic products.

## Pages

- `index.html` - Homepage with product category navigation
- `products.html` - Product listing page
- `food.html`, `skincare.html`, `healthcare.html`, `cleaning.html` - Category pages
- `about.html` - About the store
- `login.html` - User login
- `search.html` - Product search
- `usercart.html` - Shopping cart

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL (via `backend/db.php`)
- **Icons:** Font Awesome 6.5.1

## Project Structure

```
Biobasket-organic-store/
├── backend/        # PHP scripts (login, register, contact, db)
├── css/            # Stylesheets
├── js/             # JavaScript
├── images/         # Static assets
└── *.html          # Page files
```

## Getting Started

1. Clone the repository
2. Set up a local server (e.g., XAMPP or WAMP)
3. Configure database credentials in `backend/db.php`
4. Open `index.html` in your browser

## Features

- Product categories: Pulses & Dal, Spices & Masala, Health Foods, Combo Deals
- User authentication (login & register)
- Shopping cart
- Product search
- Contact form
